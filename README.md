# DeanMusic

DeanMusic is a public-facing music discovery and streaming web application.

## Free-first architecture

- Frontend: React + TypeScript + Vite
- Hosting and API: Cloudflare Pages and Workers Free
- Database: Cloudflare D1 Free
- Authentication: Better Auth
- Music archive and backup: private Google Drive
- Source control: GitHub

## Cost and safety rules

- Use free tiers only. Do not enable paid plans, metered add-ons, or billing-dependent services without Dean's explicit approval.
- Do not connect this project to Supabase.
- Do not use Cloudflare R2 in the strict zero-cost phase.
- Do not modify, connect to, or use any GENMERCH resource.
- Never commit secrets or private credentials.
- Only publish audio Dean owns or has permission to distribute and stream.

## Project status

Repository initialized. Application implementation, database migrations, authentication, playback, and deployment are planned as staged milestones.
